Oct 2026 · Healthcare · Agentic AINEW
Healthcare & AI Agents
HRRP Navigator: An AI Analyst for Hospital Readmission Penalty Risk
The majority of Medicare-eligible hospitals face active readmission penalties under CMS's Hospital Readmissions Reduction Program, yet few have a fast way to see which facilities are most exposed and why. I built an autonomous AI agent that performs this investigation end to end: it plans its own analytical sub-questions, writes and executes SQL against a relational hospital database, and synthesizes the results into a strategist's memo. I used Python and pandas to clean and join two CMS datasets into a unified SQLite database of 5,432 hospitals and 18,330 readmission records, LangGraph to orchestrate the agent's planning, querying, and reporting stages, and the Claude API to power each reasoning step, including automatic self-correction when a generated SQL query fails. The analysis identified that 77 hospitals, just 2.8% of those studied, carry the heaviest share of penalty risk, and the agent produced a targeted recommendation for where a health system should focus care-coordination resources first.
  • Used Python and pandas to clean and reconcile two CMS source files, resolving a hospital identifier format inconsistency between them before loading the data into a relational SQLite database
  • Designed a five-stage LangGraph pipeline covering planning, SQL generation, execution, synthesis, and strategist reporting, with built-in retry logic so the agent corrects its own SQL when a query fails
  • Validated every AI-generated query against hand-written baseline SQL to confirm accuracy before trusting its output
  • Tuned the SQL-generation prompts so the agent adapts its query structure to the type of business question being asked, distinguishing ranking questions from distribution questions to ensure statistically sound results
  • Published a working case study and a recorded walkthrough of a real investigation, since running the live version publicly on an ongoing basis would require a paid API budget

Oct 2026 · Banking · Risk AnalyticsNEW
Banking & Risk
Bank Early-Warning Monitor for the 2023 US Bank Failures
When Silicon Valley Bank, Signature Bank and First Republic collapsed in 2023, risk teams needed to know whether the warning signs had been visible in public data. I set out to build an early-warning screen from the quarterly Call Reports that every US bank files with regulators, and to test it against those failures.
  • I used Alteryx to clean and join four Call Report schedules per quarter for about 4,700 banks, matching records on each bank’s regulatory ID and combining two reporting formats into one consistent set of measures.
  • I calculated five risk indicators in Alteryx, including uninsured deposit share, unrealized bond losses relative to equity and two-year deposit growth, and produced an analysis-ready dataset for each quarter.
  • I used SAS to benchmark every bank against peers of similar size, ranking each indicator by percentile, flagging the top 10% and combining the ranks into a single risk score.
  • I backtested the screen on December 2022 data and applied the same pipeline to June 2026 data to produce a current watchlist for review.
  • The screen ranked SVB first of 158 large US banks ten weeks before it failed, showing that SVB combined unrealized losses equal to 98% of its equity with 94% uninsured deposits while the traditional capital check flagged none of the three failures.
  • I published the results as an interactive web tool built in JavaScript and hosted on GitHub Pages, with a data story, a watchlist and a bank lookup.
